# Brandon Keller — Portfolio Site

A multi-page portfolio site, ready to host for free on **GitHub Pages**.

**Pages:** `index.html` (home, about, projects, skills) · `grasping-chaos.html` · `flint-steel.html` · `contact.html`

## Publish it (about 5 minutes)

**Option A — GitHub website (easiest, no command line):**
1. Go to [github.com/new](https://github.com/new) and create a repository named exactly `bkeller0909.github.io` (public).
2. On the new repo page, click **uploading an existing file**, then drag in everything: the `.html` files, `style.css`, `script.js`, `favicon.svg`, and the `assets`, `images`, and `video` folders.
3. Commit. Your site is live at **https://bkeller0909.github.io** within a minute or two.

**Option B — GitHub Desktop:**
1. Install [GitHub Desktop](https://desktop.github.com/).
2. Create a repo named `bkeller0909.github.io`, copy these files into the local folder, commit, and push.

## Add your gameplay clips

1. Record gameplay with [OBS Studio](https://obsproject.com/) (free) — 10–20 second clips work best.
2. Export as **MP4** (smaller and smoother than GIFs).
3. Drop the files into `video/` (e.g. `video/fs_trailer.mp4`).
4. On `flint-steel.html`, uncomment the video block marked `GAMEPLAY CLIP` and set the right filename.
5. Re-upload the changed files to your repo.

## Keep it fresh

- The **Download resume** buttons point to `assets/Brandon_Keller_Resume.docx` — included, so they work out of the box. When you update your resume, just replace that file.
- Edit text directly in the `.html` files — plain HTML, no build tools needed.
